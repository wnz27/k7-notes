ABOUT THIS FIELD GUIDE

如何使用这本手册

面向了解类、对象、继承和组合的 Python 读者。收录 GoF 23 种设计模式，另补简单工厂。

  1. 从目录搜索问题或模式，先读一句话意图。
  2. 选择实验条件，预测最后的结果，再点「下一步」。切换另一条件做对照。
  3. 3D 模式可拖动旋转或调整滑块；视角只改变观察方向。2D 模式用箭头表示引用或消息方向。
  4. 结合 Python 示例判断代价；在「使用判断」中做一个迁移练习。

分步模型是确定性的教学示意。方块表示对象或组成部分，位置不代表真实内存布局；计数和金额是示例参数。代码不在浏览器执行。
